Bild-Toolkit
Umwandeln · Verkleinern · Freistellen

Bilder kleiner, sauberer, ohne Spuren.

iPhone-Fotos (HEIC) in JPG umwandeln, Bilder für E-Mail und Web verkleinern, Standort- und Kameradaten entfernen, Gesichter verpixeln oder den Hintergrund freistellen – alles direkt auf deinem Gerät.

Screenshot schwärzen
  • HEIC, JPG, PNG, WebP, AVIF, GIF
  • Squoosh-Codecs: MozJPEG, WebP, AVIF, OxiPNG
  • Standort & Kameradaten werden immer entfernt
  • Gesichter automatisch verpixeln
So funktioniert’s

Bilder bearbeiten, ohne sie herzugeben.

01

Kleiner speichern

Die Bildformate (JPG, WebP, AVIF, PNG) werden mit den Werkzeugen aus Squoosh gespeichert – einem Projekt von Google, das Bilder besonders klein macht, ohne dass man es sieht. iPhone-Fotos (HEIC) liest das Programm libheif.

02

Spuren entfernen

Fotos enthalten oft versteckte Angaben: wo sie aufgenommen wurden (GPS), mit welchem Handy und wann. Das Tool zeigt dir diese Angaben an und speichert das Bild ohne sie neu. Auf Wunsch macht es auch Gesichter unkenntlich – erkannt von YuNet, einem winzigen Modell aus dem OpenCV-Projekt.

03

Hintergrund freistellen

Dafür nutzt das Tool ein KI-Modell (IS-Net, bereitgestellt von IMG.LY), das erkennt, was Motiv und was Hintergrund ist. Es wird erst geladen, wenn du die Funktion nutzt (ca. 45 MB), und läuft dann auf deinem Gerät.

Keines deiner Bilder wird hochgeladen – auch nicht für das Freistellen, für das viele Online-Dienste deine Fotos auf ihre Server laden.

Hinweise zum Tool

Das Bild-Toolkit läuft vollständig in deinem Browser. Bilder werden nur im Arbeitsspeicher deines Geräts verarbeitet und nie an einen Server gesendet – die Seite darf technisch keine Verbindung zu anderen Servern aufbauen (Content Security Policy).

Open Source

Codecs aus Squoosh (Google, Apache 2.0) über jSquash: MozJPEG, libwebp, libavif, OxiPNG. HEIC: libheif (LGPL). Metadaten lesen: exifr (MIT). Freistellen: IS-Net-Modell von IMG.LY (AGPL), Gesichtserkennung: YuNet aus OpenCV Zoo (MIT), beide ausgeführt mit ONNX Runtime Web (MIT).

Metadaten

Beim Umwandeln wird nur das Bild selbst neu gespeichert. EXIF-, GPS- und andere Metadaten werden dabei nicht übernommen – die Bilder lassen sich bedenkenlos weitergeben.
